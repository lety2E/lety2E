Derivadas: senos, cosenos…

Apuntes — Tabla de derivadas

Seno
f(x)=sen⁡x  →  f′(x)=cos⁡xf(x) = \operatorname{sen} x \;\rightarrow\; f'(x) = \cos xf(x)=senx→f′(x)=cosx
Coseno
f(x)=cos⁡x  →  f′(x)=−sen⁡xf(x) = \cos x \;\rightarrow\; f'(x) = -\operatorname{sen} xf(x)=cosx→f′(x)=−senx
Tangente
f(x)=tan⁡x  →  f′(x)=sec⁡2xf(x) = \tan x \;\rightarrow\; f'(x) = \sec^2 xf(x)=tanx→f′(x)=sec2x
Logaritmo natural
f(x)=ln⁡x  →  f′(x)=1xf(x) = \ln x \;\rightarrow\; f'(x) = \dfrac{1}{x}f(x)=lnx→f′(x)=x1​
Exponencial exe^xex
f(x)=ex  →  f′(x)=exf(x) = e^x \;\rightarrow\; f'(x) = e^xf(x)=ex→f′(x)=ex
Exponencial axa^xax
f(x)=ax  →  f′(x)=axln⁡(a)f(x) = a^x \;\rightarrow\; f'(x) = a^x \ln(a)f(x)=ax→f′(x)=axln(a)
