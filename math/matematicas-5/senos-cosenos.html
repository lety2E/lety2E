Derivadas: senos, cosenos…

Apuntes — Tabla de derivadas

Seno
$f(x) = \operatorname{sen} x \;\rightarrow\; f'(x) = \cos x$
Coseno
$f(x) = \cos x \;\rightarrow\; f'(x) = -\operatorname{sen} x$
Tangente
$f(x) = \tan x \;\rightarrow\; f'(x) = \sec^2 x$
Logaritmo natural
$f(x) = \ln x \;\rightarrow\; f'(x) = \dfrac{1}{x}$
Exponencial $e^x$
$f(x) = e^x \;\rightarrow\; f'(x) = e^x$
Exponencial $a^x$
$f(x) = a^x \;\rightarrow\; f'(x) = a^x \ln(a)$

Ejemplo

Deriva la siguiente función usando la tabla. El término con $x$ en el denominador se convierte primero a exponente negativo:

$f(x) = -5x - \dfrac{4}{x^3} + 5 \ln x + 6 \cos x - 3 \operatorname{sen} x - 4e^x + 6^x - 5 \tan x - 1$
$-\dfrac{4}{x^3} = -4x^{-3} \quad \text{derivando} \quad 12x^{-4} = \dfrac{12}{x^4}$
$f'(x) = -5 + \dfrac{12}{x^4} + \dfrac{5}{x} - 6 \operatorname{sen} x - 3 \cos x - 4e^x + 6^x \ln 6 - 5 \sec^2 x$

Ejercicios

Bloque único
$f(x) = -5x - \dfrac{4}{x^3} + 2 \ln x + 7 \cos x - 4 \operatorname{sen} x + 7e^x - 2^x + 10$
$f(x) = 3 \tan x - 7 + \dfrac{8}{x^3} - 2x^4 + 8 \operatorname{sen} x - 9 \cos x - \dfrac{6}{x} + 4^x - 3$
$f(x) = 8 \operatorname{sen} x - \ln x + 6x^4 - \dfrac{3}{x^2} - 7^x + 2e^x + x - \tan x$
$f(x) = -4 \operatorname{sen} x + 6 \tan x - 8 \cos x - \dfrac{4}{x^7} - 2x^3 + 7 - 9^x$
$f(x) = -9 \cos x - 8 + \dfrac{4}{x^6} + 4x^8 - 6 \tan x - 4 \operatorname{sen} x - \dfrac{x}{2} + 8^x - 2$

Respuestas

▼
Bloque único
$$f(x) = -5x - \frac{4}{x^3} + 2 \ln x + 7 \cos x - 4 \operatorname{sen} x + 7e^x - 2^x + 10$$
$-\dfrac{4}{x^3} = -4x^{-3} \quad \text{derivando} \quad 12x^{-4} = \dfrac{12}{x^4}$
$$\mathbf{f'(x) = -5 + \frac{12}{x^4} + \frac{2}{x} - 7 \operatorname{sen} x - 4 \cos x + 7e^x - 2^x \ln 2}$$
$$f(x) = 3 \tan x + \frac{8}{x^3} - 2x^4 + 8 \operatorname{sen} x - 9 \cos x - \frac{6}{x} + 4^x - 10$$
$\dfrac{8}{x^3} = 8x^{-3} \quad \text{derivando} \quad -24x^{-4} = -\dfrac{24}{x^4}$
$-\dfrac{6}{x} = -6x^{-1} \quad \text{derivando} \quad 6x^{-2} = \dfrac{6}{x^2}$
$$\mathbf{f'(x) = 3 \sec^2 x - \frac{24}{x^4} - 8x^3 + 8 \cos x + 9 \operatorname{sen} x + \frac{6}{x^2} + 4^x \ln 4}$$
$$f(x) = 8 \operatorname{sen} x - \ln x + 6x^4 - \frac{3}{x^2} - 7^x + 2e^x + x - \tan x$$
$-\dfrac{3}{x^2} = -3x^{-2} \quad \text{derivando} \quad 6x^{-3} = \dfrac{6}{x^3}$
$$\mathbf{f'(x) = 8 \cos x - \frac{1}{x} + 24x^3 + \frac{6}{x^3} - 7^x \ln 7 + 2e^x + 1 - \sec^2 x}$$
$$f(x) = -4 \operatorname{sen} x + 6 \tan x - 8 \cos x - \frac{4}{x^7} - 2x^3 + 7 - 9^x$$
$-\dfrac{4}{x^7} = -4x^{-7} \quad \text{derivando} \quad 28x^{-8} = \dfrac{28}{x^8}$
$$\mathbf{f'(x) = -4 \cos x + 6 \sec^2 x + 8 \operatorname{sen} x + \frac{28}{x^8} - 6x^2 - 9^x \ln 9}$$
$$f(x) = -9 \cos x + \frac{4}{x^6} + 4x^8 - 6 \tan x - 4 \operatorname{sen} x - \frac{x}{2} + 8^x - 10$$
$\dfrac{4}{x^6} = 4x^{-6} \quad \text{derivando} \quad -24x^{-7} = -\dfrac{24}{x^7}$
$$\mathbf{f'(x) = 9 \operatorname{sen} x - \frac{24}{x^7} + 32x^7 - 6 \sec^2 x - 4 \cos x - \frac{1}{2} + 8^x \ln 8}$$
