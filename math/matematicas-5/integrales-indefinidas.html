Matemáticas 5 · Tema 13

Integrales indefinidas

Apuntes — Formulario de integración

Constante
$\displaystyle \int k \, dx = kx + c$
Potencia
$\displaystyle \int x^n \, dx = \dfrac{x^{n+1}}{n+1} + c$
Uno entre x
$\displaystyle \int \dfrac{1}{x} \, dx = \ln|x| + c$
Seno
$\displaystyle \int \operatorname{sen} x \, dx = -\cos x + c$
Coseno
$\displaystyle \int \cos x \, dx = \operatorname{sen} x + c$
Secante al cuadrado
$\displaystyle \int \sec^2 x \, dx = \tan x + c$
Exponencial $e^x$
$\displaystyle \int e^x \, dx = e^x + c$
Exponencial $a^x$
$\displaystyle \int a^x (\ln a) \, dx = a^x + c$

Ejemplo

Se integra término a término, cada uno con su fórmula del formulario:

$$\begin{aligned} &\int \left( 5x^2 + 4\operatorname{sen} x - 2 + 3\sec^2 x + \frac{5}{x} + 7e^x \right) dx = \\ &= \mathbf{\frac{5x^3}{3} - 4\cos x - 2x + 3\tan x + 5\ln|x| + 7e^x + c} \end{aligned}$$

Respuestas

▼
Bloque 1
$$\begin{aligned} &\int \left( 4\sec^2 x - 8x + 6 - 3\operatorname{sen} x + 4e^x - 6x^4 \right) dx = \\ &= 4\tan x - \frac{8x^2}{2} + 6x - 3(-\cos x) + 4e^x - \frac{6x^5}{5} + c = \\ &= \mathbf{4\tan x - 4x^2 + 6x + 3\cos x + 4e^x - \frac{6x^5}{5} + c} \end{aligned}$$
$$\begin{aligned} &\int \left( -4\cos x - 5 + \frac{3}{x} - 2^x \ln 2 - 8x^3 + 4e^x \right) dx = \\ &= -4\operatorname{sen} x - 5x + 3\ln|x| - 2^x - \frac{8x^4}{4} + 4e^x + c = \\ &= \mathbf{-4\operatorname{sen} x - 5x + 3\ln|x| - 2^x - 2x^4 + 4e^x + c} \end{aligned}$$
$$\begin{aligned} &\int \left( 5\operatorname{sen} x - 4 - 7x^4 - \frac{5}{x} + 7\sec^2 x - 5x \right) dx = \\ &= 5(-\cos x) - 4x - \frac{7x^5}{5} - 5\ln|x| + 7\tan x - \frac{5x^2}{2} + c = \\ &= \mathbf{-5\cos x - 4x - \frac{7x^5}{5} - 5\ln|x| + 7\tan x - \frac{5x^2}{2} + c} \end{aligned}$$
Bloque 2
$$\begin{aligned} &\int \left( 6 - 7x^2 - \frac{8}{x} + 4\cos x - 7^x \ln 7 - e^x \right) dx = \\ &= \mathbf{6x - \frac{7x^3}{3} - 8\ln|x| + 4\operatorname{sen} x - 7^x - e^x + c} \end{aligned}$$
$$\begin{aligned} &\int \left( 2\operatorname{sen} x - 9x^2 + 6x^3 - \frac{3}{x} + 2e^x - 4\cos x \right) dx = \\ &= 2(-\cos x) - \frac{9x^3}{3} + \frac{6x^4}{4} - 3\ln|x| + 2e^x - 4\operatorname{sen} x + c = \\ &= \mathbf{-2\cos x - 3x^3 + \frac{3x^4}{2} - 3\ln|x| + 2e^x - 4\operatorname{sen} x + c} \end{aligned}$$
$$\begin{aligned} &\int \left( 7x^2 - 4x + \frac{3}{x} - 2 + 4e^x - 5\operatorname{sen} x - \sec^2 x \right) dx = \\ &= \frac{7x^3}{3} - \frac{4x^2}{2} + 3\ln|x| - 2x + 4e^x - 5(-\cos x) - \tan x + c = \\ &= \mathbf{\frac{7x^3}{3} - 2x^2 + 3\ln|x| - 2x + 4e^x + 5\cos x - \tan x + c} \end{aligned}$$
