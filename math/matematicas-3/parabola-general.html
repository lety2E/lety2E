Ecuación general de la parábola

Ejemplo

$(x - h)^2 = \pm 4p(y - k)$

Con el signo + la parábola abre hacia arriba; con el signo −, hacia abajo. $p$ es la distancia del vértice al foco.

foco$(-4, 3)$
directriz$y = -1$
vértice$(-4, 1)$
p$2$
$$\begin{aligned} (x - (-4))^2 &= +4(2)(y - (1)) \\ (x + 4)^2 &= +8(y - 1) \\ x^2 + 8x + 16 &= 8y - 8 \\ x^2 + 8x + 16 - 8y + 8 &= 0 \end{aligned}$$
$x^2 + 8x - 8y + 24 = 0$

Comprobación

$$\begin{aligned} (-8)^2 + 8(-8) - 8(3) + 24 &= 0 \\ 64 - 64 - 24 + 24 &= 0 \\ 0 &= 0 \end{aligned}$$
$$\begin{aligned} (0)^2 + 8(0) - 8(3) + 24 &= 0 \\ 0 + 0 - 24 + 24 &= 0 \\ 0 &= 0 \end{aligned}$$

Respuestas

▼
Ejercicio 1
foco$(-4, 3)$
directriz$y = -5$
vértice$(-4, -1)$
p$4$
$$\begin{aligned} (x - (-4))^2 &= +4(4)(y - (-1)) \\ (x + 4)^2 &= +16(y + 1) \\ x^2 + 8x + 16 &= 16y + 16 \\ x^2 + 8x + 16 - 16y - 16 &= 0 \end{aligned}$$
$x^2 + 8x - 16y = 0$

Comprobación

$$\begin{aligned} (-12)^2 + 8(-12) - 16(3) &= 0 \\ 144 - 96 - 48 &= 0 \\ 144 - 144 &= 0 \\ 0 &= 0 \end{aligned}$$
$$\begin{aligned} (4)^2 + 8(4) - 16(3) &= 0 \\ 16 + 32 - 48 &= 0 \\ 48 - 48 &= 0 \\ 0 &= 0 \end{aligned}$$
Ejercicio 2
foco$(-5, 2)$
directriz$y = 6$
vértice$(-5, 4)$
p$2$
$$\begin{aligned} (x - (-5))^2 &= -4(2)(y - (4)) \\ (x + 5)^2 &= -8(y - 4) \\ x^2 + 10x + 25 &= -8y + 32 \\ x^2 + 10x + 25 + 8y - 32 &= 0 \end{aligned}$$
$x^2 + 10x + 8y - 7 = 0$

Comprobación

$$\begin{aligned} (-9)^2 + 10(-9) + 8(2) - 7 &= 0 \\ 81 - 90 + 16 - 7 &= 0 \\ 97 - 97 &= 0 \\ 0 &= 0 \end{aligned}$$
$$\begin{aligned} (-1)^2 + 10(-1) + 8(2) - 7 &= 0 \\ 1 - 10 + 16 - 7 &= 0 \\ 17 - 17 &= 0 \\ 0 &= 0 \end{aligned}$$
Ejercicio 3
foco$(3, 2)$
directriz$y = -4$
vértice$(3, -1)$
p$3$
$$\begin{aligned} (x - (3))^2 &= +4(3)(y - (-1)) \\ (x - 3)^2 &= 12(y + 1) \\ x^2 - 6x + 9 &= 12y + 12 \\ x^2 - 6x + 9 - 12y - 12 &= 0 \end{aligned}$$
$x^2 - 6x - 12y - 3 = 0$

Comprobación

$$\begin{aligned} (-3)^2 - 6(-3) - 12(2) - 3 &= 0 \\ 9 + 18 - 24 - 3 &= 0 \\ 27 - 27 &= 0 \\ 0 &= 0 \end{aligned}$$
$$\begin{aligned} (9)^2 - 6(9) - 12(2) - 3 &= 0 \\ 81 - 54 - 24 - 3 &= 0 \\ 81 - 81 &= 0 \\ 0 &= 0 \end{aligned}$$
Ejercicio 4
foco$(2, 1)$
directriz$y = 7$
vértice$(2, 4)$
p$3$
$$\begin{aligned} (x - (2))^2 &= -4(3)(y - (4)) \\ (x - 2)^2 &= -12(y - 4) \\ x^2 - 4x + 4 &= -12y + 48 \\ x^2 - 4x + 4 + 12y - 48 &= 0 \end{aligned}$$
$x^2 - 4x + 12y - 44 = 0$

Comprobación

$$\begin{aligned} (-4)^2 - 4(-4) + 12(1) - 44 &= 0 \\ 16 + 16 + 12 - 44 &= 0 \\ 44 - 44 &= 0 \\ 0 &= 0 \end{aligned}$$
$$\begin{aligned} (8)^2 - 4(8) + 12(1) - 44 &= 0 \\ 64 - 32 + 12 - 44 &= 0 \\ 76 - 76 &= 0 \\ 0 &= 0 \end{aligned}$$
